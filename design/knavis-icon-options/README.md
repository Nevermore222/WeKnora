# Knavis main logo options

These are internal-brand design candidates only. They are not wired into the
Xelora client or server.

## Files

- knavis-light.svg: 1303x504 wordmark for light backgrounds.
- knavis-dark.svg: 1303x504 wordmark for dark backgrounds.
- knavis.png: raster preview of knavis-light.svg.
- knavis-dark.png: raster preview of knavis-dark.svg.

The existing Xelora assets remain unchanged. After approval, the internal
release branch can replace only the two main logo assets while leaving the
favicon, desktop app icon, provider icons, and layout unchanged.
