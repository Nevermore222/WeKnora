参考 1 · Aceternity 渐变宣传分栏

强烈推荐左侧表单 + 右侧宣传SVG 渐变动效

参考 2 · 21st Login Card 粒子背景

强烈推荐居中卡片粒子/渐变背景

来源 → 21st.dev (Ruixen UI)

参考 3 · Linear 极简 App 登录

桌面 App 风极简大按钮栈
居中 Logo + 大圆角按钮，Desktop 客户端气质；可加 subtle 背景动效。
来源 → Linear

参考 4 · Notion 居中卡片 + 社交登录

卡片式产品 Slogan

来源 → Notion

参考 5 · Vercel 极简开发者风

极简黑白
干净、克制；动效需额外叠加（如网格/粒子背景）。
来源 → Vercel
